# Algorithms

| Need                                     | Algorithm      | Complexity     |
| ---------------------------------------- | -------------- | -------------- |
| One source → all nodes (neg. weights ok) | Bellman-Ford   | O(V·E)         |
| One source → all nodes (no neg. weights) | Dijkstra       | O((V+E) log V) |
| Any node -> Any Node                     | Floyd-Warshall | O(V³)          |
